evergreen-terrace is a personal engineering org built for a one-person OSS shop — it provides the PM, engineering team, and momentum tracking that Nick otherwise lacks when professional workload crowds out OSS context-switching. It works through role-scoped agents (pm, eng-senior, eng-mid, eng-junior, voice, director, momentum-sentinel) that are defined in `agents/`, loaded with domain knowledge from `skills/`, and oriented by shared conventions in `steering/`; a GasTown-style parallel orchestrator (conductor) breaks goals into discrete beads, dispatches them to parallel Claude Code workers, and tracks all state to disk so restarts resume cleanly. The persistent work queue, backed by TOML files in `queue/` and `context/`, is exposed via a Bun HTTP server on port 2727, with a web dashboard on 2728, a metrics service on 2729, a momentum sentinel on 2730, and the conductor on 2731. Phases 1 through 3 are complete, delivering the queue server, the full agent roster, a terminal and web dashboard, and Jira/GitLab/Figma integrations. Phase 4 is in progress, targeting the metrics collection service, dashboard trend views, a Tauri native desktop wrapper, and the conductor's parallel execution engine.
