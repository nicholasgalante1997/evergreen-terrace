# Skills

Skills are shared knowledge bases that agents pull from on demand. They live in `skills/` and are referenced in agent definitions. A skill is a `SKILL.md` file — structured documentation that an agent reads before acting in a specific domain.

## `nick-voice`

**Path:** `skills/nick-voice/SKILL.md`

The voice model for Nick's written register. Built from writing samples across emails, Webex messages, technical blog posts, and workplace communication.

Covers:
- Sentence structure and rhythm
- Register and code-switching across contexts
- How to state opinions directly
- Technical explanation patterns
- What to strip from AI-generated output (filler phrases, passive voice, over-structured responses)
- Format rules by context type
- Transformation examples with before/after

Used by: `voice`, `pm`, `stakeholder`
