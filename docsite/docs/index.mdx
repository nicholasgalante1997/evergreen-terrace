# evergreen-terrace

A personal engineering org for a one-person shop operating at principal scope.

The bottleneck isn't access or management — it's team support. evergreen-terrace provides the PM, design, and engineering team that doesn't otherwise exist. Role-scoped agents handle the work that would otherwise fall to a full team. A persistent work queue tracks everything. A momentum sentinel surfaces what's going stale before it becomes a problem.

## What it is

evergreen-terrace is a Bun/TypeScript Turbo monorepo containing:

- **A work queue** — TOML-backed, served over HTTP, with inbox → active → completed lifecycle
- **A web dashboard** — three-pane React UI with real-time agent feed, dispatch controls, and approval gates
- **A metrics service** — append-only event log, velocity charts, project health history
- **A sentinel** — on-demand or scheduled project health scoring with ranked reports and a browser-viewable report
- **A conductor** — parallel agent orchestrator that executes queue items non-interactively in the correct project directory, with a streaming output feed and review gate for code-producing work
- **An agent team** — eight role-scoped Claude Code agents covering PM, engineering, voice, stakeholder, and director functions
- **A skill library** — shared knowledge bases that agents load into their system prompts

## The problem it solves

A principal-level engineer without team support spends a significant portion of their time on work that should be delegated: ticket grooming, design specs, PR descriptions, stakeholder updates, project health monitoring. That's not a skills gap — it's a staffing gap.

evergreen-terrace addresses it by making the engineer the only human in the loop, but only at decisions that require human judgment:

1. **What to build** — PM gate
2. **How to build it** — Tech lead gate
3. **Whether it's good enough** — Review gate
