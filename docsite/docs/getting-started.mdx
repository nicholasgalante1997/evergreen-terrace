# Getting Started

## Prerequisites

- **Bun** `>= 1.3.13` — `bun --version`
- **Claude Code CLI** — `claude --version` must return a path; this is how agents are invoked
- **mise** (optional) — `mise --version`; provides the task runner interface
- `ANTHROPIC_API_KEY` set in your environment

## Install

```sh
git clone <repo-url> evergreen-terrace
cd evergreen-terrace
bun install
```

## Environment

```sh
cp .env.example .env
```

Open `.env` and set `QUEUE_ROOT`:

```sh
# Required — tells all services where to find queue/, context/, and beads/
QUEUE_ROOT=/path/to/evergreen-terrace

# Optional — override the claude binary path if not on $PATH
CLAUDE_PATH=/usr/local/bin/claude
```

`QUEUE_ROOT` defaults to `process.cwd()` if unset, which works when running from the repo root.

## Start everything

```sh
bun run start
# or: mise run start
```

This builds all packages and starts all services:

| Service       | Port |
| ------------- | ---- |
| queue-server  | 2727 |
| web dashboard | 2728 |
| metrics       | 2729 |
| sentinel      | 2730 |
| conductor     | 2731 |

After ~3 seconds, your browser opens to `http://localhost:2728`.

**Skip the rebuild** (after the first run):

```sh
bun run start:dev
# or: mise run start:dev
```

## Remote access

If you're accessing the DGX remotely over SSH, use the tunnel script on your laptop:

```sh
# Copy to your laptop once:
scp nicks-dgx:~/dev/evergreen-terrace/scripts/tunnel.sh ~/bin/evergreen-tunnel
chmod +x ~/bin/evergreen-tunnel

# Run from your laptop whenever you want to access the dashboard:
evergreen-tunnel
```

This forwards all service ports to `localhost` on your laptop and opens the browser automatically.

## Running individual services

```sh
bun run queue      # queue-server only — port 2727
bun run sentinel   # sentinel server only — port 2730
bun run metrics    # metrics only — port 2729
bun run conductor  # conductor only — port 2731
bun run dashboard  # web dashboard dev server — port 2728
bun run tui        # terminal dashboard
```

## Adding a work item manually

Create a TOML file in `queue/inbox/`:

```toml
[item]
id = "abc-001"
title = "Implement foresight Phase 2 analysis engine"
project = "foresight"
type = "feature"
priority = "p1"
created = "2026-05-08T00:00:00"
source = "manual"

[delegation]
agent = "eng-mid"
delegated_at = ""

[context]
description = "Phase 1 is complete. Phase 2 adds the analysis engine..."
acceptance = """
- [ ] foresight-core/src/analysis/ module created
- [ ] analyze() pure function implemented
- [ ] cargo clippy -- -D warnings clean
"""
links = ["~/dev/foresight/foresight-core/src/"]
```

The queue server picks it up on the next request — no restart required.

## Syncing agents

The 8 agent definitions in `agents/` are installed globally to `~/.claude/agents/` for use in any Claude Code session. They sync automatically via the PostToolUse hook in `.claude/settings.json` whenever you edit `agents/`, `skills/`, or `steering/` through Claude Code.

Manual sync:

```sh
bun run sync-agents
# or: mise run sync-agents
```
